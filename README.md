# 🎮 Vasu Studio

Welcome to the official repository of **Vasu Studio** — an independent game development studio dedicated to crafting engaging, high-quality, and highly secure 2D interactive mobile experiences with absolute transparency.

This hub powers our studio's primary web presence, showcases our live game portfolio, and houses our localized user data protection frameworks.

---

## 🚀 Live Portfolio & Highlights

We create high-quality 2D mobile games using Unity and C#.

### 🌌 Live Projects
*   **Space Pilot:** Our flagship high-octane casual space arcade experience, fully live on production platforms.
*   **Strategy Board Collection:** Featuring localized variants like *Tiger & Goat (Bagh Bakri)* and *Red & Green* modes, complete with custom rewards spin-wheels and adaptive internal AI opponents.
*   **2D Physics Vehicle Engine:** Advanced physics environments featuring custom wheel simulation and precise Ackermann steering logic.
*   **Multi-Board Snake & Ladder:** Multi-board layout mechanics integrated with modular localization arrays and typography styling.

## 🛠️ Ecosystem & Integrations

Our games and web systems leverage industry-standard architecture to guarantee performance and policy compliance:

*   **Game Development:** Unity Engine, C# Scripting.
*   **Platform & Distribution:** Android SDK target architectures, Google Play Console release tracks, and community closed testing infrastructure.
*   **Monetization & Analytics:** Secure multi-network mediation through **Google AdMob** and **ironSource LevelPlay**.
*   **Web Frameworks:** Clean HTML5, CSS3 Custom Properties, Responsive Layouts, and Google Firebase Realtime integration.
